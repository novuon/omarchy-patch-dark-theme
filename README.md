# Patch Dark

An ink ground, paper-grey text and one signal red.
A precise, restrained Omarchy theme with photoreal audio wallpapers, each
with an intro that plays when you switch to the theme. Its sibling is
[Patch Light](https://github.com/novuon/omarchy-patch-light-theme).

```sh
omarchy-theme-install https://github.com/novuon/omarchy-patch-dark-theme
```

## Wallpapers

Stylus, Console, Folded Dimension, Crosspoint, Acoustic Core and a plain
framed sheet. Each has a six-second intro in `backgrounds/intros/` that ends on the
still.

## Colours

Every colour is defined exactly, in every file, and text reads at 4.5:1 or
more on the ground.

| Role | Colour | Use | On the ground |
|---|---|---|---|
| background | `#141715` | the ground | 1.0:1 |
| lighter_background | `#1e221f` | raised: cards, message blocks | 1.1:1 |
| foreground | `#c2c7c3` | text | 10.5:1 |
| light_foreground | `#9a9f9b` | secondary text | 6.7:1 |
| muted | `#878c88` | muted text | 5.3:1 |
| border | `#2a2e2b` | hairlines between panels | 1.3:1 |
| accent | `#e43055` | signal red: markers, fills, the active state | 4.2:1 |
| selection | `#4a1d28` | selected rows | 1.3:1 |

It was made for Patch, the pro audio environment for Omarchy, and needs
nothing from it.
